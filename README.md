Carbon is a graphical user interface for [yt-dlp](https://github.com/yt-dlp/yt-dlp)  
It inherits not only its powerful features but its limitations as well.

I created Carbon as a way to make my yt-dlp downloads easier and faster.  
May it be useful for someone else out there.

> [!NOTE]
Cookie Usage & Privacy:  
Some sites require browser cookies to allow downloads through yt-dlp.  
Due to permission restrictions on Windows, automatic cookie collection may be blocked by the system.  
For the best experience using cookie-dependent features, it is currently recommended to run Carbon on a Linux powered device.
